Word Positions (row, columns 0..10)
-----------------------------------
ÄS ISCH    : row 0, columns 0..1 & 3..6  (0b1101111000000000)
VIERTEL    : row 1, columns 0..6         (0b1111111000000000)
ZÄNI       : row 1, columns 7..10        (0b0000000111100000)
FÜFUZWÄNZG : row 2, columns 1..10        (0b0111111111100000)
ZWÄNZG     : row 2, columns 5..10        (0b0000011111100000)
FÜFI       : row 3, columns 0..3         (0b1111000000000000)
VOR        : row 3, columns 5..7         (0b0000011100000000)
AB         : row 3, columns 8..9         (0b0000000011000000)
HALBI      : row 4, columns 0..4         (0b1111100000000000)
GSI        : row 9, columns 8..10        (0b0000000011100000)

Hours:
1  EIS     : row 6, columns 8..10        (0b0000000011100000)
2  ZWEI    : row 5, columns 3..6         (0b0001111000000000)
3  DRI     : row 5, columns 0..2         (0b1110000000000000)
4  VIERI   : row 8, columns 5..9         (0b0000011111000000)
5  FÜFI    : row 5, columns 7..10        (0b0000000111100000)
6  SÄGSCHI : row 9, columns 0..6         (0b1111111000000000)
7  SIBNI   : row 8, columns 0..4         (0b1111100000000000)
8  ACHTI   : row 7, columns 6..10        (0b0000001111100000)
9  NINI    : row 6, columns 0..3         (0b1111000000000000)
10 ZÄNI    : row 4, columns 6..9         (0b0000001111000000)
11 ELFI    : row 6, columns 4..7         (0b0000111100000000)
12 ZWELFI  : row 7, columns 0..5         (0b1111110000000000)
